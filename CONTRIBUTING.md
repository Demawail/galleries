# Contributing

Small, focused pull requests and reproducible setup reports are welcome. Describe the problem, the proposed change and how you tested it. Larger changes should begin with an issue so we can discuss scope. Responses and merges are subject to available maintainer time.

Use the pinned package manager and lockfile. Run `node build.mjs` from the repository root after installing Galleries dependencies. For changes to authentication, sharing, downloads or storage, also run the relevant checks in docs/VALIDATION.md on an isolated installation.

Use fictional names and test images. Keep credentials, live database exports, client links, personal emails and photographs out of issues, commits and screenshots. Contributions should be compatible with the project MIT license; preserve third-party notices.
