# Pilot acceptance checklist
Packaging checks: no inherited Sites identity, runtime data, source client documents, portfolio photographs or secrets. Gallery seed is empty and the original project-specific upgrade was removed.

Before using real client work, verify on fresh accounts:
- dependency install, typecheck, builds, new Sites IDs and migrations;
- private owner access denied to unauthenticated outsiders;
- new test gallery, own uploaded images, scoped client link, cross-gallery denial;
- shared pins and quotas, note recovery, submit/reopen history, each download variant;
- revoked and expired client links stop working, private notes never in client responses;
- Lightroom connect, publish, republish preserving pins, retrieve selects and gallery-scoped contributor key;
- verified email sign-in, remembered browser review attachment, expired magic-link rejection, private gallery history across devices;
- Resend verified-domain notification and manual enrollment behavior;
- data export, deletion and actual operating costs.

The kit is not yet certified through a complete fresh-account or Lightroom installation. Build results for this release are recorded in the original installation’s pilot report. Do not infer an external end-to-end test from the source package.
