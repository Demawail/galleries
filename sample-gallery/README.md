# Sample gallery: The Coastal Guesthouse

This fictional assignment includes three AI-generated images created for this project on October 26, 2026. They depict no real client, commissioned shoot or identified property. They are synthetic demonstration assets, not examples of Josh Rose’s photography. You may use and redistribute them with this demonstration; preserve this disclosure when showing them as the sample gallery.

## Load the sample on your own installation

Ask your coding assistant to read gallery.json and guide you through the normal gallery workflow, one step at a time. This JSON is a setup recipe, not a database dump or an import endpoint. The application starts empty; nothing is inserted into an existing workspace automatically.

1. Create a new gallery with the title and fictional client in gallery.json. Use today’s shoot date and a closing date 30 days from today.
2. Add Exterior and Interior sections, then upload the three bundled PNGs through the ordinary uploader. This creates real storage-backed test files, so client links and downloads exercise the same path as your own uploads.
3. Assign sections, star the exterior photograph, use it as the cover, set two client pins and enable downloads. Add the sample public and private notes from gallery.json.
4. Open the gallery, create a new scoped client link, and visit it in a signed-out browser. Pin two photographs and add a note to the interior image. Confirm the private owner note is absent.
5. Submit the selections, return to the owner view and verify they arrived. Test a download. If configured, add a sample image to a portfolio draft, keeping its demo label, and check the public result.
6. Revoke the client link and verify access stops. When finished, delete the sample gallery using the normal owner controls. Any copies added to Portfolio must be removed there separately. Source images in this folder can be deleted independently.

Use your own account credentials and newly issued gallery links. Never share a real client link in a bug report. Provider storage and request charges can apply to this test.
